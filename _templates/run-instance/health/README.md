# health/ — timestamped health reports

One markdown report per run of the health check (Level 5, card 05):

```
YYYY-MM-DD_HHMM_health.md      ← e.g. 2026-08-17_0930_health.md
```

Generated from `../../../_templates/health-report.md` — read-only commands only. Newest file = current state; the series = the server's trend over time. Ask your agent any time: *"run the health check on this server."*
